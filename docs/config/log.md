# 日志配置

对应配置文件的 `log` 项。

| 键            | 类型   | 默认值                           | 说明                                                                              |
|---------------|--------|----------------------------------|-----------------------------------------------------------------------------------|
| `enabled`     | bool   | `true`                           | 是否写日志文件。关闭后日志只输出到标准错误；在 Windows 服务模式下则完全丢弃日志。 |
| `filename`    | string | `<数据目录>/logs/neokikoeru.log` | 日志文件路径。目录不存在时会自动创建。                                            |
| `max_size`    | int    | `50`                             | 单个日志文件的最大体积，**单位 MB**。超过即切分。                                 |
| `max_backups` | int    | `30`                             | 最多保留的历史日志文件个数。`0` 表示不限制。                                      |
| `max_age`     | int    | `28`                             | 历史日志保留天数，**单位天**。`0` 表示不按时间清理。                              |
| `compress`    | bool   | `true`                           | 是否用 gzip 压缩轮转后的历史日志。                                                |

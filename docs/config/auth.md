# 认证配置

对应配置文件的 `auth` 项。

| 字段                    | 类型     | 默认值         | 说明                                                                                         |
|-------------------------|----------|----------------|----------------------------------------------------------------------------------------------|
| `jwt_secret`            | string   | 自动生成       | 登录令牌的签名密钥，首次启动时随机生成。**请勿泄露或随意修改**，修改后所有用户需要重新登录。 |
| `token_expires_in`      | int      | `7`            | 登录令牌的有效期（**天**）。                                                                 |
| `webauthn.rp_id`        | string   | `""`           | 通行密钥的 RP ID，通常是可注册域名，**不带端口、不带协议**。                                 |
| `webauthn.origins`      | string[] | `[]`           | 允许发起通行密钥仪式的来源白名单，如 `https://neokikoeru.example.com`。                      |
| `webauthn.display_name` | string   | `"Neokikoeru"` | 注册通行密钥时展示给用户的站点名称，留空回退为默认值。                                       |

浏览器对 WebAuthn 有硬性要求，不满足时注册/登录会报错：

- 必须通过 **HTTPS** 访问；只有 `localhost` / `*.localhost` 允许 HTTP。
- 必须使用**域名**访问，直接用 IP 地址访问会被拒绝。
- 反向代理不要剥离 `Origin` 头，否则会报 `missing Origin header`。

# DLsite 配置

对应配置文件的 `dlsite` 项。

| 键                    | 类型   | 默认值              | 说明                                                                        |
|-----------------------|--------|---------------------|-----------------------------------------------------------------------------|
| `locale`              | string | `"zh-CN"`           | 向 DLsite 请求元数据时使用的语言。可选 `ja-JP`、`en-US`、`zh-CN`、`zh-TW`。 |
| `covers_dir`          | string | `<数据目录>/covers` | 封面图缓存目录。                                                            |
| `trim_outer_brackets` | bool   | `true`              | 是否剥离作品名首尾被括号完整包裹的片段。                                    |
| `proxy_url`           | string | `""`                | 内部参数，普通用户请忽略。                                                  |
| `proxy_secret`        | string | `""`                | 内部参数，普通用户请忽略。                                                  |

补充说明：

- `trim_outer_brackets` 用于清理形如 `【早期購入特典】作品名(CV: xxx)` 这类名称的首尾装饰性括号片段，让标题更整洁。它只处理
  **完整包裹首尾**的括号，不会误删标题中间的括号内容；若剥离后为空则保留原样。关掉它则标题与 DLsite 原始展示完全一致。
